# C64-Raycasting (DOOM & Wolfenstein Style 160x200 Multicolor Bitmap Engine)

3D Raycasting движок в графическом режиме **160x200 Multicolor Bitmap** для легендарного компьютера **Commodore 64 (MOS 6510 @ 1.0 MHz, 64 KB RAM, VIC-II, SID)**.

Движок ушел от текстового режима / ASCII / PETSCII к настоящей полноэкранной многоцветной попиксельной графике высокого разрешения (160×200 пикселей) с полноценными текстурами стен, пола и потолка в духе **DOOM** и **Wolfenstein 3D**.

---

## 🎮 Особенности нового движка

- **Полноценный графический режим 160x200 (Multicolor Bitmap Mode)**:
  - Никакого ASCII или PETSCII-символов — отрисовка идет напрямую в растровую видеопамять VIC-II (`$6000`–`$7F3F`, Bank 1) с попиксельной палитрой в экранной памяти (`$4000`) и Color RAM (`$D800`).
  - Полноэкранный 3D-вид без раздражающего интерфейса на все 200 строк экрана.
- **DOOM-текстуры стен**:
  - **DOOM Steel Wall (Стальная стена)**: стальные бронелисты, горизонтальные швы стыков и заклепки со световыми бликами.
  - **Castle Blue Stone with Gold Medallion**: каменная кладка с золотым замковым орденом/крестом в центре.
  - **Wood Paneling (Деревянные панели)**: вертикальные древесные волокна, пазы и рейки.
  - **Red Brick (Красный кирпич)**: горизонтальные и смещенные вертикальные растворные швы между кирпичами.
  - **DOOM AirLock Door (Шлюзовая гермодверь)**: усиленная стальная рама, защитные пластины и золотой электронный кодовый замок.
- **Освещение и глубина**:
  - Направленное затенение стен (X/Y Shading): грани, ориентированные на север/юг, отображаются в более глубоком темном оттенке, создавая четкое ощущение 3D-геометрии.
  - Перспективный текстурированный пол и темный потолок.
- **Управление с Джойстика в Port 2 (основное)**:
  - Полная поддержка аппаратного джойстика в Port 2:
    - **Вверх / Вниз**: Перемещение вперед / назад
    - **Влево / Вправо**: Поворот камеры
    - **Кнопка Fire**: Открыть дверь / действие
    - **Fire + Влево/Вправо**: Стрейф (движение боком)
  - Клавиатура (WASD / Стрелки / Пробел) также полностью поддержана.
- **Производительность**:
  - 16-битный целочисленный DDA raycaster без медленной 32-битной арифметики.
  - 0 операций деления во время отрисовки кадров (таблицы шагов LUT `v_step_table`).
  - Пакетная очистка и заполнение ячеек памяти без холостых циклов.
- **Звук**:
  - Звуковые эффекты шагов и открывания дверей через аудиочип **MOS 6581 (SID)**.

## 🕹 Управление

### Джойстик (Port 2) — Рекомендуется:
| Действие | Джойстик (Port 2) |
| :--- | :--- |
| **Вперед** | Рычаг Вверх |
| **Назад** | Рычаг Вниз |
| **Поворот влево** | Рычаг Влево |
| **Поворот вправо** | Рычаг Вправо |
| **Стрейф влево** | Удерживать Fire + Рычаг Влево |
| **Стрейф вправо** | Удерживать Fire + Рычаг Вправо |
| **Открыть дверь** | Кнопка Fire (одиночное нажатие) |

### Клавиатура:
| Действие | Клавиша |
| :--- | :--- |
| **Вперед / Назад** | `W` / `S` или Стрелки вверх / вниз |
| **Поворот** | `A` / `D` или Стрелки влево / вправо |
| **Открыть дверь** | `Пробел (Space)` или `Enter` |
| **Тактическая карта** | `M` |
| **Выход** | `X` |

## 🛠 Сборка проекта

### Сборка в Windows:
Запустите скрипт сборки:
```cmd
build.bat
```

Или вручную:
```cmd
cl65 -t c64 -O -o raycast.prg src/tables.c src/map.c src/raycast.c src/render.c src/main.c
```

На выходе компилируется бинарный файл **`raycast.prg`** (~7.6 КБ).

---

## 🚀 Запуск в эмуляторе

1. **VICE (x64sc / x64)**:
   ```cmd
   x64sc.exe raycast.prg
   ```
   В настройках эмулятора убедитесь, что Джойстик 2 (Port 2) настроен на клавиатурный NumPad или геймпад.
2. **Web-эмуляторы C64**:
   Загрузите `raycast.prg` в веб-эмулятор C64.
