# C64-Raycasting (Wolfenstein 3D Engine for Commodore 64)

3D Raycasting движок в стиле **Wolfenstein 3D** для легендарного ретро-компьютера **Commodore 64 (MOS 6510 @ 1.0 MHz, 64 KB RAM, VIC-II, SID)**.

Проект написан на C и оптимизирован под кросс-компилятор **cc65** с использованием передовых техник 8-битного рендеринга в реальном времени.

---

## 🎮 Особенности движка

- **Полноэкранный 3D-вид (Full Screen 40x25)**:
  - Никакого загромождения интерфейсом (HUD отключен) — чистый, атмосферный вид от первого лица на все 25 строк экрана.
- **Базовые 3D-текстуры стен**:
  - **Красный кирпич (Red Brick)**: горизонтальные и смещенные вертикальные линии раствора кладки (mortar joints) светлого цвета.
  - **Серый камень (Grey Stone)**: 3D-фаски (bevel) с бликами сверху/слева и тенями снизу/справа.
  - **Синий замок (Blue Stone)**: каменная синяя окантовка с золотыми эмблемами/крестами по центру.
  - **Дерево (Wood Panel)**: вертикальные планки, стыки досок и текстура древесины.
  - **Дверь (Door)**: металлическая дверная коробка, панели и золотая дверная ручка.
  - Перспективный пол с плиточными швами и точечный темный потолок.
  - Автоматическое затенение граней (светлые X-стены и темные Y-стены) и дистанционный дизеринг в темноте.
- **Непрерывное плавное управление по WASD**:
  - Прямое сканирование матрицы клавиатуры через **CIA #1 ($DC00 / $DC01)** — полное отсутствие задержек буфера KERNAL!
  - Поддержка одновременного зажатия нескольких клавиш (например, бег вперед `W` с одновременным поворотом `A` или `D`).
- **3D Тактическая карта (клавиша `[M]`)**:
  - Псевдо-3D рельефная карта лабиринта с объемным отображением стен, маркером игрока и лучом направления взгляда.
- **Производительность**:
  - Высокая скорость работы (**~15–20 FPS**) на 1-мегагерцовом процессоре 6502.
  - Быстрая арифметика **8.8 Fixed-Point** и таблицы LUT (тригонометрия, DDA дельты, fish-eye, высоты). **0 делений в рантайме!**
- **Звук**:
  - Звуковые эффекты шагов и открытия дверей через чип **MOS 6581 (SID)**.

## 🕹 Управление

| Действие | Клавиатура | Джойстик (Port 2) |
| :--- | :--- | :--- |
| **Вперед** | `W` или Стрелка вверх | Вверх |
| **Назад** | `S` или Стрелка вниз | Вниз |
| **Поворот влево** | `A` или Стрелка влево | Влево |
| **Поворот вправо** | `D` или Стрелка вправо | Вправо |
| **Стрейф влево** | `Q` | — |
| **Стрейф вправо** | `E` | — |
| **Открыть дверь** | `Пробел (Space)` | Кнопка Fire |
| **3D Тактическая карта** | `M` | — |
| **Выход** | `X` | — |

## 🛠 Сборка проекта

### Требования:
- Компилятор [cc65](https://cc65.github.io/cc65/) (утилита `cl65`)
- Python 3 (для генерации тригонометрических таблиц `generate_tables.py`)

### Сборка в Windows:
Запустите скрипт сборки:
```cmd
build.bat
```

Или вручную через `cl65`:
```cmd
cl65 -t c64 -O -o raycast.prg src/tables.c src/map.c src/raycast.c src/render.c src/main.c
```

На выходе компилируется файл **`raycast.prg`** (~8.8 КБ).

---

## 🚀 Запуск в эмуляторе

Файл `raycast.prg` можно запускать в любом C64-эмуляторе:

1. **VICE (x64sc / x64)**:
   ```cmd
   x64sc.exe raycast.prg
   ```
   Или перетащите файл `raycast.prg` в окно эмулятора.
2. **Web-эмуляторы C64**:
   Загрузите `raycast.prg` в любой браузерный эмулятор (например, VirtualC64 Web или C64 online).
3. **Реальный Commodore 64**:
   Загрузка через SD2IEC, EasyFlash, Kung Fu Flash или 1541 Ultimate:
   ```basic
   LOAD"RAYCAST.PRG",8,1
   RUN
   ```

## 📂 Структура репозитория

```
64-raycasting/
├── .gitignore             # Игнорируемые файлы
├── README.md              # Документация проекта
├── build.bat              # Скрипт сборки под Windows
├── Makefile               # Скрипт сборки для GNU Make
├── generate_tables.py     # Генератор таблиц предрасчета LUT (25 строк)
├── raycast.prg            # Готовый бинарник для Commodore 64
└── src/
    ├── config.h           # Полноэкранные размеры 40x25, адреса CIA1, цвета, символы текстур
    ├── fixed.h            # 8.8 Fixed-point типы и макросы
    ├── tables.h           # Заголовочный файл LUT
    ├── tables.c           # Таблицы Sin, DDA Delta, Fish-eye, Height
    ├── map.h              # Заголовочный файл карты и типов тайлов
    ├── map.c              # 16x16 карта лабиринта с интерактивными дверями
    ├── raycast.h          # Определение лучей и координаты текстур tex_u
    ├── raycast.c          # Ядро DDA Raycasting алгоритма с расчетом текстур
    ├── render.h           # Рендерер 3D сцены
    ├── render.c           # 3D шейдер текстур (кирпич, камень, дерево, дверь, пол, потолок) и 3D карта
    └── main.c             # Непрерывный опрос матрицы CIA1 для WASD, движение, звук SID
```
