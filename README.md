# C64-Raycasting (Wolfenstein 3D Engine for Commodore 64)

3D Raycasting движок в стиле **Wolfenstein 3D** для легендарного ретро-компьютера **Commodore 64 (MOS 6510 @ 1.0 MHz, 64 KB RAM, VIC-II, SID)**.

Проект написан на C и оптимизирован под кросс-компилятор **cc65** с использованием передовых техник 8-битного рендеринга в реальном времени.

---

## 🎮 Особенности движка

- **Высокая скорость работы (~15–20 FPS)** на реальном процессоре MOS 6510 / 6502 с частотой всего ~1 МГц.
- **Алгоритм DDA (Digital Differential Analyzer)** для точного нахождения пересечений лучей со стенами без искажений.
- **Быстрая арифметика с фиксированной точкой (8.8 Fixed-Point)**: отсутствие медленных вычислений с плавающей точкой.
- **Таблицы предрасчета (LUT)**: тригонометрия (Sin, Cos), дельты шагов, устранение эффекта рыбьего глаза (*fish-eye correction*) и таблица проекции высоты стен. **0 операций деления во время рейкастинга каждого кадра!**
- **Графика и стилистика Wolfenstein 3D**:
  - 40 горизонтальных лучей на полный экран VIC-II.
  - Разные типы стен: Серый камень, Синий камень, Деревянные панели, Красный кирпич, Двери.
  - Автоматическое затенение граней (светлые X-стены и темные Y-стены для объемного восприятия глубины).
  - Дистанционный дизеринг (dither pattern) для удаленных стен.
- **HUD в стиле Wolfenstein 3D**:
  - Здоровье (Health), очки (Score), этаж (Floor), координаты и угол обзора.
  - **Живой мини-радар**: отображает локальную карту вокруг игрока и стены в реальном времени.
  - Полноэкранная тактическая карта подземелья по нажатию клавиши `[M]`.
- **Интерактивность**:
  - Открытие дверей по нажатию `[Space]`.
  - Скольжение вдоль стен при столкновениях (Wall sliding).
  - Звуковые эффекты через звуковой чип **MOS 6581 (SID)** при ходьбе.
  - Поддержка клавиатуры и джойстика в Port 2.

## 🕹 Управление

| Действие | Клавиатура | Джойстик (Port 2) |
| :--- | :--- | :--- |
| **Вперед** | `W` или Стрелка вверх | Вверх |
| **Назад** | `S` или Стрелка вниз | Вниз |
| **Поворот влево** | `A` или Стрелка влево | Влево |
| **Поворот вправо** | `D` или Стрелка вправо | Вправо |
| **Стрейф влево** | `Q` | — |
| **Стрейф вправо** | `E` | — |
| **Действие / Открыть дверь** | `Пробел (Space)` | Кнопка Fire |
| **Тактическая карта** | `M` | — |
| **Выход** | `X` | — |

## 🛠 Сборка проекта

### Требования:
- Компилятор [cc65](https://cc65.github.io/cc65/) (утилита `cl65`)
- Python 3 (для автоматической генерации таблиц `generate_tables.py`, уже включен)

### Сборка в Windows:
Просто запустите скрипт сборки:
```cmd
build.bat
```

Или вручную через `cl65`:
```cmd
cl65 -t c64 -O -o raycast.prg src/tables.c src/map.c src/raycast.c src/render.c src/main.c
```

На выходе будет скомпилирован исполняемый файл **`raycast.prg`** (~8.7 КБ), готовый для запуска на C64 или в эмуляторе.

---

## 🚀 Запуск в эмуляторе

Файл `raycast.prg` можно запускать в любом C64-эмуляторе:

1. **VICE (x64sc / x64)**:
   ```cmd
   x64sc.exe raycast.prg
   ```
   Или перетащите файл `raycast.prg` в окно эмулятора.
2. **Web-эмуляторы C64**:
   Можно загрузить `raycast.prg` в любой браузерный эмулятор (например, VirtualC64 Web или C64 online).
3. **Реальный Commodore 64**:
   Загрузка через SD2IEC, EasyFlash, Kung Fu Flash, 1541 Ultimate или кассетный адаптер:
   ```basic
   LOAD"RAYCAST.PRG",8,1
   RUN
   ```

├── build.bat              # Скрипт сборки под Windows
├── Makefile               # Скрипт сборки для GNU Make

    ├── config.h           # Конфигурация, адреса памяти VIC-II/SID/CIA
    ├── fixed.h            # 8.8 Fixed-point типы и макросы
    ├── tables.h           # Заголовочный файл таблиц LUT
    ├── tables.c           # Предрассчитанные тригонометрические таблицы

    ├── map.c              # 16x16 карта лабиринта с дверями
    ├── raycast.h          # Заголовочный файл лучевого кастинга

    ├── render.c           # Отрисовка в память экрана ($0400) и цвета ($D800), HUD
